Export from WhatsApp in 60 seconds

Four taps in WhatsApp, one drop into WA Archiver — no account, no upload.

1

Open the chat

In WhatsApp, open the chat and tap the contact or group name (Android) or the chat name (iPhone).

2

Tap "Export chat"

Scroll down and tap Export chat — Android: ⋮ More → Export chat · iPhone: Export Chat.

3

With or without media

Choose Without media for a small .txt, or Include media for a .zip with photos and voice notes.

4

Import into WA Archiver

Save or share the file, then open WA Archiver and import it — drag & drop works too. Everything stays on your device.

FAQ

Short answers to what people ask before installing.

🔒Is my data uploaded anywhere?

No. Parsing, storage and search happen entirely in your browser or on your device — there is no account and no server. The only optional network calls are AI features you trigger yourself with your own key.

✈️Does it work offline?

Yes. The web app is an installable PWA and the Android APK is fully offline-first — already-imported chats, media and stats open without a connection.

📁Which formats are supported?

Standard WhatsApp chat exports: plain .txt files and .zip archives that include media. You can import several chats at once.

👥Are groups supported?

Yes — group chats get per-sender colors, group analytics, reactions and everything that 1:1 chats have.

📱Android app vs web app?

They're the same app, v1.5.0. The APK is the offline-first packaged build, while the web app installs as a PWA straight from your browser.

💚Is it free / open source?

Yes — WA Archiver is open source under the MIT License, and the source lives on GitHub. No accounts, subscriptions or paywalls.

⚖️Is it affiliated with WhatsApp or Meta?

No. WA Archiver is an independent tool that only reads export files you produce from WhatsApp. "WhatsApp" is a trademark of its respective owner.

Run it on your machine

Node 20+ and Bun. Or skip all of this and just install the APK.

# install & run
git clone https://github.com/Avithegod2010/WA-archiver.git
cd wa-archiver && bun install
cp .env.example .env && bun run db:push
bun run dev   # → http://localhost:3000
